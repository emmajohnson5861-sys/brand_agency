# Project concept image prompts

Created using the built-in ImageGen tool. These are original illustrative concept studies, not claims of commissioned client work. Each board is delivered as responsive WebP at 480, 800 and 1280 pixels wide; originals remain in the ignored local `.publish/project-image-originals` folder.

## Jack Petpals

Assets: `public/images/latest-work/concept-petpals-{480,800,1280}.webp`

Prompt:

Use case: product-mockup. Asset type: a landscape branding case-study image for a design agency portfolio website, aspect ratio approximately 5:3. Create ONE polished original brand presentation board, organized into a refined 3-column by 2-row mosaic of SIX panels with narrow off-white gutters, all panels belonging to the SAME brand. Mix flat graphic identity panels with convincing photographed physical mockups. Art direction inspired by sophisticated Behance brand identity presentations: strong logo scale, precise visual hierarchy, generous breathing room, tactile paper, crisp print detail, restrained directional lighting and realistic shadows. Full bleed board, no browser frame, no laptop website screenshots, no surrounding website UI, no watermark, no extraneous paragraphs, no tiny illegible body text. Use only the exact brand name as readable lettering, plus very limited specimen letters. Brand mark must repeat consistently on the mockups. It must look like a carefully designed identity system, not a collection of unrelated images. This is an illustrative concept study, not a claim of commissioned client work.
Brand name (verbatim): "Jack Petpals".
Palette: warm tangerine orange, butter yellow, ivory, charcoal.
Panels and subject: premium natural pet-treat packaging: neatly arranged pouches, a paw-inspired geometric brand mark, bold clean wordmark, palette swatches, a typography panel, printed kraft cards and a simple storefront sign.
